# Gshi

Простой веб‑журнал для отслеживания посещаемости учеников.

## Возможности

- Добавление учеников в список.
- Создание уроков по дате и теме.
- Отметка статуса посещения: `Присутствовал`, `Отсутствовал`, `Опоздал`.
- Автоматический подсчёт статистики по каждому ученику.
- Сохранение данных в `localStorage`.
- Современный дизайн в стиле ярких AI‑интерфейсов (вдохновлён эстетикой ChatGPT Image).

## Запуск

Откройте файл `index.html` в браузере.

## Структура

- `index.html` — разметка.
- `styles.css` — стили интерфейса.
- `app.js` — логика журнала.
